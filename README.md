# Coursera Machine Learning Specialization - Courses 1 & 2 Projects

[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Overview

This repository contains a collection of projects and exercises completed as part of the first two courses of the Coursera Machine Learning Specialization taught by Andrew Ng:

1.  **Supervised Machine Learning: Regression and Classification:** This course covers fundamental supervised learning algorithms, including linear regression, logistic regression, and basic neural networks.
2.  **Advanced Learning Algorithms:** Building upon the first course, this one delves into more advanced techniques such as deep neural networks, support vector machines (SVMs), and unsupervised learning methods (though this repository primarily focuses on the supervised learning aspects from this course).

The projects aim to provide a practical understanding of the theoretical concepts learned in these courses through hands-on implementation and experimentation.

## Key Concepts and Techniques Demonstrated

**From Supervised Machine Learning: Regression and Classification:**

* **Linear Regression:** Implementation for predicting continuous values using gradient descent.
* **Logistic Regression:** Implementation for binary and multi-class classification (one-vs-all).
* **Neural Networks:** Building and training simple feedforward neural networks for classification.
* **Cost Functions:** Understanding and implementing cost functions like squared error and cross-entropy.
* **Gradient Descent:** Implementing and applying the gradient descent optimization algorithm.
* **Feature Engineering and Scaling:** Techniques for preparing data for machine learning models.
* **Model Evaluation:** Basic methods for assessing the performance of regression and classification models.

**From Advanced Learning Algorithms:**

* **Deep Neural Networks:** Building and training multi-layer neural networks using TensorFlow and Keras.
* **Support Vector Machines (SVMs):** Implementation and application of SVMs with different kernel functions (linear, RBF) for classification.
* **Kernel Methods:** Understanding the concept and application of kernel functions in SVMs.
* **Regularization:** Techniques to prevent overfitting in neural networks and SVMs.
* **Optimization Algorithms:** Utilizing advanced optimizers like Adam for training neural networks.

1.  **Prerequisites:**
    * Python 3.x
    * NumPy
    * Pandas
    * Matplotlib
    * SciPy (for loading `.mat` files)
    * Scikit-learn
    * TensorFlow
    * Keras
    * Jupyter Notebook

    You can install the necessary libraries using pip:
    ```bash
    pip install numpy pandas matplotlib scipy scikit-learn tensorflow
    ```

2.  **Running the Code:**
    * Navigate to the specific project directory within `course1/` or `course2/`.
    * Open the relevant `.ipynb` Jupyter Notebook and follow the instructions within to execute the code and explore the implementations and results.
